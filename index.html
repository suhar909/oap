🎯 Aim Assist Mod

Мод для Minecraft Java 1.21.4 (Fabric)

Minecraft 1.21.4 Fabric Loader Fabric API Java 21

📦 Файлы мода созданы!

Все исходные файлы мода уже созданы в этом проекте. Ниже — инструкция по сборке .jar файла и загрузке на GitHub.

Для сборки нужен JDK 21. Скачайте с adoptium.net

🚀 Сборка мода

1

Скачайте проект (или скопируйте файлы)

2

Откройте терминал в папке проекта и выполните:

# Если есть Gradle:
gradle wrapper --gradle-version=8.12
./gradlew build

# Или используйте скрипт:
chmod +x quick-build.sh
./quick-build.sh
3

Готовый .jar файл:

build/libs/aim-assist-1.0.0.jar

📤 Загрузка на GitHub

1

Создайте репозиторий на github.com/new

2

Загрузите код:

git init
git add .
git commit -m "Aim Assist Mod for MC 1.21.4 Fabric"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/aim-assist-mod.git
git push -u origin main
3

GitHub Actions автоматически соберёт .jar файл!
Скачайте из вкладки Actions → Build Mod → артефакт

📥 Установка в Minecraft

1

Установите Fabric Loader для 1.21.4

2

Скачайте Fabric API для 1.21.4

3

Скопируйте aim-assist-1.0.0.jar в папку .minecraft/mods/

4

Запустите Minecraft с профилем Fabric!

❓ Решение проблем

Build failed: "Could not resolve..."

Проверьте интернет. Gradle скачивает зависимости при первой сборке (~200MB).

"Unsupported class file major version"

Нужна Java 21. Проверьте: java -version

Мод не загружается

Убедитесь что Fabric API установлен в папке mods/.

gradlew: Permission denied

Выполните: chmod +x gradlew
